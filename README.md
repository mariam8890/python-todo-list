
# Python To-Do List

A simple **console-based To-Do List application built with Python**.
The project allows users to create, view, organize, and manage their tasks through an interactive command-line menu.

## 📌 Features

* Add new tasks
* View all tasks
* Mark tasks as completed
* View task categories
* Store task information using dictionaries
* Manage multiple tasks using lists
* Prevent duplicate categories using sets
* Interactive command-line menu

## 💻 How It Works

When the program starts, it displays an interactive menu:

```text
1. Add Task
2. View Tasks
3. Mark Task as Completed
4. View Categories
5. Exit
```

Users can select an option by entering its corresponding number.

### Task Structure

Each task is stored as a Python dictionary containing:

```text
ID
Title
Category
Priority
Completion Status
Notes
```

All tasks are stored inside a list, allowing the application to manage multiple tasks.
